MakroPRO — User Story (Reference)
🖥 UI Layer⚡ API Layer
As a MakroPRO customer, I want to add a new product to the basket and confirm it is immediately available through the product API, so that customers can browse and purchase it without delay.
Acceptance Criteria
  • Customer logs in with valid credentials — redirected to homepage
  • Browse/search and select a product to view the detail page
  • Clicking "Add to Basket" updates icon count and shows confirmation within 2s
  • POST /api/v2/basket/items returns HTTP 201 with product_id and quantity
  • GET /api/v2/basket returns product with status: "available" within 3s
  • Out-of-stock → button disabled; API returns 422 with reason "out_of_stock"
  • Adding same product twice → quantity increments, no duplicate item
  • Unauthenticated add → redirect to login; API returns 401
